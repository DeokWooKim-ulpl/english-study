## 2. 12주 단계별 목표

| 주차 | 단계 | 독해 | 작문 | 말하기 | 마일스톤 |
|---|---|---|---|---|---|
| 1–2 | 적응 | 과학 뉴스(짧은 글) | 기본 이메일(문의, 감사, 일정) | 스크립트: 자기소개, 연구 1분 소개 | 매일 루틴 14일 유지 |
| 3–4 | 기초 | arXiv 초록 | 공동연구 제안·자료 요청 메일 | 스몰토크, 커피브레이크 | 이메일 템플릿 10개 완성 |
| 5–6 | 학술 표현 | 논문 Introduction | Abstract 작성 (본인 연구) | 포스터 세션 설명 | 본인 연구 Abstract 1편 |
| 7–8 | 구조 | 논문 Method/Result | Method·Result 문단, 그림 캡션 | 발표 후 Q&A (예상 질문 20개) | Q&A 답변 스크립트 |
| 9–10 | 논증 | Discussion, 리뷰 논문 | Discussion, Reviewer 회신 | 5분 발표 리허설 | 5분 발표 녹음 리포트 |
| 11–12 | 종합 | 관심 분야 최신 논문 전체 | Cover letter, 전체 초고 다듬기 | 10~12분 학회 발표 + Q&A 모의 | 모의 학회 발표 완주 |

13주차부터: 약점 분석 결과로 다음 사이클 재설계 (같은 구조, 난이도↑).

## 3. 주간 리뷰 (일요일, 10분)
- 앱 대시보드에서 확인: 복습 완료율, 신규 카드 수, 모듈별 학습 일수
- 반복 오류 Top 3 (예: 관사, 시제, 전치사) → 다음 주 집중 카드 지정
- 미학습 모듈이 있으면 다음 주 루틴에서 우선 배정

## 4. 평가 지표
| 영역 | 지표 | 측정 방법 |
|---|---|---|
| 독해 | 분당 단어 수(WPM), 이해도 문제 정답률 | 리더 화면 타이머 + 퀴즈 |
| 작문 | 문장당 교정 수, 반복 오류 감소율 | Gemini 피드백 로그 |
| 말하기 | 말하기 속도(WPM), 필러 빈도, 교정 문장 수 | 세션 리포트 |
| 복습 | 기억 유지율(retention) | FSRS 통계 |
