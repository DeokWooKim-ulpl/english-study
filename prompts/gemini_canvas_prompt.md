# Gemini Canvas 구현 프롬프트

> 2026-11-06 · v1.0 · 계획 v2(docs/04_PLAN_v2.md)의 요구사항을 Gemini Canvas 단일 앱으로 옮긴 버전

## 사용법
1. Gemini 앱(gemini.google.com) → 입력창 **Canvas** 선택
2. 아래 **[1] 메인 프롬프트** 전체를 붙여넣고 실행
3. 결과가 잘리거나 일부 기능이 빠지면 **[2] 추가 프롬프트**를 순서대로 하나씩 입력
4. 완성 후 Canvas 우측 상단 **공유** → "Gemini 기능 사용"과 "세션·기기 간 데이터 저장" 켜기, **"사용자 간 데이터 공유"는 끄기** (켜면 링크를 아는 누구나 내 기록을 보고 수정 가능)
5. 공유 링크를 폰·태블릿·PC 브라우저에서 열고 홈 화면에 추가

## Canvas에서 되는 것 / 안 되는 것
| 항목 | 상태 | 근거 |
|---|---|---|
| 앱 안에서 Gemini 호출 (API 키 불필요) | 가능 | **[커뮤니티]** 비공식 동작. Google이 예고 없이 바꿀 수 있음 ([note.com](https://note.com/r_nakano/n/n63304d81a7b8?hl=en)) |
| 기기 간 데이터 저장 (Firestore) | 가능 | **[공식]** [Canvas safety & security](https://support.google.com/gemini/answer/16419134?hl=en) |
| 백그라운드 자동 실행 (앱을 안 열어도 자료 수집) | **불가** | Canvas 앱은 열었을 때만 동작 → 앱을 처음 여는 순간 "오늘 자료"를 생성하게 설계 |
| 실제 웹 기사 자동 수집 | 제한적 | 앱 안에서 다른 사이트 접속이 막힐 수 있음 [추정] → 원문 붙여넣기 + Gemini 생성 지문으로 대응 |
| 휴대폰 알림 | **불가** | Gemini 앱 "작업"으로 매일 아침 알림 → [3] 프롬프트 |

## [1] 메인 프롬프트 (복사해서 사용)

````
너는 시니어 프론트엔드 개발자이자 영어 교육 설계자다. Canvas에서 동작하는 단일 파일 React 앱 "English Study"를 만들어줘.

# 0. 사용자
- 물리·광학(레이저/포토닉스) 분야 박사 연구자. 한국인.
- 목표: (1) 영어 원문 독해 (2) 논문·이메일 작문 (3) 말하기: 일상 대화 + 학회 발표·Q&A·연구 대화
- 관심 키워드(설정에서 수정 가능): ultrafast laser, nonlinear optics, photonics
- 앱 UI 언어: 한국어. 학습 내용: 영어. 설명·피드백 이유: 한국어.

# 1. 기술 조건
- 휴대폰·태블릿·PC 모두에서 쓰기 좋은 반응형 레이아웃. 폰은 하단 탭바, 태블릿·PC는 좌측 사이드바.
- 다크 모드 지원.
- 데이터 저장: Canvas가 제공하는 Firestore 사용, 사용자별 비공개 경로에 저장 (기기 간 동기화 목적). Firestore를 쓸 수 없으면 localStorage로 대체하고 화면 상단에 "이 기기에만 저장 중" 경고 표시.
- 모든 데이터는 절대 삭제하지 않는다 (보관 처리만). 모든 항목에 id, createdAt, updatedAt 저장.
- Gemini 호출: Canvas 앱에서 쓰는 방식으로 Gemini 모델을 호출하는 공통 함수 callGemini(prompt, schema)를 만든다.
  - 응답은 반드시 JSON. 파싱 실패 시 1회 재시도, 그래도 실패하면 원문 응답을 저장하고 "다시 시도" 버튼 표시.
  - 호출 중에는 로딩 표시, 오류 메시지는 한국어로.
- 설정 화면: 키워드, 현재 주차(1~12), 하루 신규 카드 상한(기본 10), 하루 복습 상한(기본 50), JSON 내보내기/가져오기(백업용).

# 2. 화면 구성 (탭 6개)

## 2.1 홈 "오늘"
- 오늘 할 일 체크리스트 4칸: ① 복습 카드 N장 ② 독해 1편 ③ 작문 1개 ④ 말하기 스크립트 1개 (요일별 규칙은 4절)
- 각 칸 완료 여부 자동 반영, 연속 학습일(streak), 이번 주 달성률(%), 12주 계획상 현재 주차와 이번 주 목표 표시
- 미학습 알림: 3일 이상 하지 않은 모듈은 빨간 배지 + "오늘 꼭 하기" 문구
- 하루의 첫 접속 시 오늘 자료(독해 지문, 작문 과제, 말하기 스크립트)가 없으면 Gemini로 자동 생성해서 저장. 같은 날 다시 열면 저장된 것을 보여준다.

## 2.2 독해
- 자료 소스 2가지:
  (a) Gemini 생성: 카테고리 research(키워드 관련 논문 초록 스타일, 200~300단어) / news(과학 뉴스 스타일) / daily(일상 에세이) 중 오늘 1편 + 원하면 추가 생성
  (b) 원문 붙여넣기: 내가 arXiv·논문·기사 원문을 붙여넣으면 같은 형식으로 분석
- 분석 결과 JSON: title, category, cefr, sentences[], summary_ko(3줄), phrases[5]{en, ko, example}, questions[3]{q, answer, explanation_ko}
- 리더 화면: 문장 단위 표시, 문장 탭 → 한국어 번역 토글, 표현 탭 → 뜻·예문 + [카드로 저장]
- 이해도 질문 3개: 답 입력 → 정답·해설 공개 → 틀린 문제는 자동으로 복습 카드 생성
- 읽기 시간 측정(분당 단어 수 WPM 계산해 저장)

## 2.3 작문
- 과제 유형: 이메일(문의/공동연구 제안/자료 요청/리뷰어 회신/일정 조율/감사), 논문(Abstract/Introduction/Method/Result/Discussion/Cover letter/Rebuttal), 한→영 영작(한국어 문장 5개)
- 오늘의 과제 1개 자동 제시(요일 규칙) + 자유 작문 가능
- 과제 화면: 상황 설명(한국어), 요구 조건, 참고 표현 5개, [모범 답안 보기]는 제출 후에만 열림
- **[Gemini로 피드백] 버튼**: 내 글을 Gemini에 보내 아래 JSON으로 받는다
  { corrected, sentence_pairs[]{original, corrected, why_ko, error_type}, error_types[] (article|tense|preposition|agreement|word_order|vocabulary|tone|structure), alternatives[2], formality(1~5), overall_comment_ko, model_answer }
- 피드백 화면: 원문 vs 교정본 차이를 색으로 표시(삭제=빨강 취소선, 추가=초록), 문장별 이유, 오류 유형 칩, 대안 표현, 격식도
- 내 원문과 피드백은 모두 저장. 교정된 문장 쌍(sentence_pairs)은 자동으로 "교정 카드"가 된다.
- 같은 과제를 다시 쓰면 버전 1, 2, 3…으로 이력 저장, 버전 간 비교 가능.

## 2.4 말하기 (스크립트 낭독)
- 하루 1개만 제시. 많이 주지 않는다.
  - 평일: 120~150단어(약 1분), 토요일: 발표형 250단어(약 2분), 일요일: 없음
- 스크립트 JSON: title, type(daily|coffee_break|research_intro|qa_answer|lab_meeting|presentation), script, script_marked(끊어 읽기 위치를 " / "로, 강세 단어를 **굵게**), key_phrases[3]{en, ko}, tip_ko(발음·억양 팁 1줄), est_seconds
- 화면: 스크립트(표시 버전/일반 버전 전환), 핵심 표현 3개, 브라우저 TTS로 듣기 버튼(속도 0.8×/1.0×), 타이머
- 체크: [읽었음] 버튼 필수, 선택 입력: 읽은 횟수(1~5), 스스로 평가(1~5). 했는지 여부는 홈 체크리스트와 통계에 반영.
- 못 한 스크립트는 다음날 1개까지만 이월. 더 오래된 것은 "밀린 스크립트" 목록으로 보관(강제하지 않음).
- 핵심 표현 3개는 자동으로 카드 생성.

## 2.5 복습
- 카드 종류: phrase(뜻→표현), correction(내가 틀린 문장→교정 문장+이유), translate(한국어→모범 영작), comprehension(독해 질문→정답)
- 앞면 표시 → [정답 보기] → 4개 버튼 평가: 다시(Again) / 어려움(Hard) / 좋음(Good) / 쉬움(Easy)
- 일정 계산은 SM-2 변형으로 정확히 이렇게 구현:
  - 카드 초기값: ease=2.5, interval=0일, reps=0
  - Again: reps=0, interval=0 (오늘 다시 출제), ease=max(1.3, ease-0.2)
  - Hard: interval=max(1, round(interval*1.2)), ease=max(1.3, ease-0.15)
  - Good: reps==0이면 1일, reps==1이면 3일, 그 외 round(interval*ease)
  - Easy: Good 간격×1.3, ease+=0.15
  - due = 오늘 + interval, 매 평가를 reviews 기록에 저장(cardId, rating, reviewedAt)
- 하루 신규 카드·복습 상한 설정값 적용. 밀린 카드가 많으면 오래된 것부터.

## 2.6 보관함 (언제든 꺼내보기)
- 탭: 독해 자료 / 표현 / 내 작문+피드백 / 말하기 스크립트 / 카드
- 날짜 범위, 유형, 오류 유형, 태그 필터 + 검색창
- 작문 상세: 과제 → 버전별 내 원문 → 피드백 → 재작성 이력을 한 화면에
- 어떤 항목이든 [다시 공부하기] 버튼 → 해당 화면으로 열기

## 2.7 통계·정기 복습 (홈 하단 또는 별도 탭)
- 모듈별 학습 일수(주간/월간), 누적 카드 수, 복습 정답률, 독해 WPM 추이, 오류 유형 Top 5 추이
- 주간 복습(일요일): 1·2·4주 전에 쓴 작문 1개를 원문 숨긴 채 "다시 쓰기" → 피드백 → 이전 버전과 오류 수 비교
- 이번 주 반복 오류 Top 3 → 해당 교정 카드만 모아 집중 복습 세션
- 월간 리포트(매월 말일 또는 버튼): Gemini가 한 달 기록 요약(학습일, 오류 변화, 자주 쓴 표현, 다음 달 제안)을 한국어로 작성해 저장

# 3. 12주 학습 계획 (앱에 내장, 주차에 따라 생성 난이도·주제 조정)
| 주차 | 독해 | 작문 | 말하기 스크립트 | 마일스톤 |
| 1–2 | 과학 뉴스(짧은 글) | 기본 이메일(문의, 감사, 일정) | 자기소개, 연구 1분 소개 | 14일 연속 |
| 3–4 | arXiv 초록 | 공동연구 제안·자료 요청 메일 | 스몰토크, 커피브레이크 | 이메일 템플릿 10개 |
| 5–6 | 논문 Introduction | 본인 연구 Abstract | 포스터 세션 설명 | Abstract 1편 |
| 7–8 | 논문 Method/Result | Method·Result 문단, 그림 캡션 | 발표 후 Q&A 답변 | Q&A 답변 20개 |
| 9–10 | Discussion, 리뷰 논문 | Discussion, Reviewer 회신 | 5분 발표 일부 | 발표 스크립트 낭독 5회 |
| 11–12 | 최신 논문 전체 | Cover letter, 초고 다듬기 | 10~12분 발표 + Q&A | 발표 스크립트 완주 |
12주 후에는 약점 통계를 반영해 같은 구조로 난이도를 올려 반복.

# 4. 요일 규칙
| | 월 | 화 | 수 | 목 | 금 | 토 | 일 |
| 작문 | 이메일 | 한→영 | 논문 | 이메일 | 논문 | 한→영 | 주간 다시 쓰기 |
| 말하기 | 일상 | 커피브레이크 | 연구 소개 | Q&A 답변 | 랩미팅 | 발표(2분) | 없음 |
하루 목표 시간 약 45분: 복습 10분, 독해 15분, 작문 15분, 말하기 5분. 바쁜 날은 복습만 해도 streak 유지.

# 5. 품질 기준
- 첫 화면이 바로 쓸 수 있는 상태여야 한다 (빈 화면 금지, 첫 실행 시 오늘 자료 자동 생성).
- 모든 버튼은 실제로 동작해야 한다. 미구현 기능을 "준비 중"으로 남기지 말 것.
- Gemini가 생성하는 영어는 자연스러운 학술·실무 영어, 한국어 설명은 간결하게.
- 코드는 하나의 파일. 기능별 컴포넌트로 나누고 주석은 한국어로.
````

## [2] 추가 프롬프트 (메인 결과가 부족할 때 하나씩)

**2-1. 기능 점검**
```
지금 앱에서 메인 요구사항 중 빠지거나 동작하지 않는 기능을 목록으로 점검하고, 전부 구현해줘. 특히 (1) Firestore 저장/불러오기 (2) [Gemini로 피드백] 결과의 원문-교정본 차이 색 표시 (3) 복습 일정 계산 (4) 말하기 [읽었음] 체크와 홈 체크리스트 연동 (5) 하루 첫 접속 시 오늘 자료 자동 생성.
```

**2-2. 보관함·통계 강화**
```
보관함에 날짜 범위·유형·오류 유형 필터와 검색을 넣고, 작문 상세에서 버전별 원문·피드백 비교를 한 화면에 보여줘. 통계 탭에 모듈별 학습 일수, 복습 정답률, 오류 유형 Top 5 추이 그래프를 추가해줘.
```

**2-3. 정기 복습**
```
일요일 "주간 다시 쓰기"(1·2·4주 전 작문을 원문 숨기고 재작성 → 피드백 → 이전 버전과 오류 수 비교)와 "이번 주 반복 오류 Top 3 집중 복습", 그리고 [월간 리포트 생성] 버튼을 구현해줘. 리포트는 저장되고 보관함에서 다시 볼 수 있어야 해.
```

**2-4. 백업**
```
설정에 [전체 데이터 JSON 내보내기]와 [JSON 가져오기(기존 데이터와 id 기준 병합, 삭제 없음)]를 넣어줘. 마지막 백업 후 7일이 지나면 홈에 백업 알림을 띄워줘.
```

**2-5. 폰 UI 다듬기**
```
폰 화면(세로 390px 기준)에서 글자 크기, 버튼 크기(최소 44px), 하단 탭바, 키보드가 올라왔을 때 작문 입력창이 가려지지 않게 다듬어줘.
```

## [3] 아침 알림용 Gemini "작업" (선택)

Canvas 앱은 알림을 보낼 수 없으므로, Gemini 앱 → 작업 → 매일 07:30 반복으로 등록:
```
나는 광학 연구자이고 영어 학습 앱으로 매일 공부한다. 오늘 요일에 맞는 할 일을 3줄로 알려줘.
요일 규칙 — 작문: 월 이메일, 화 한→영, 수 논문, 목 이메일, 금 논문, 토 한→영, 일 주간 다시 쓰기 /
말하기 스크립트: 월 일상, 화 커피브레이크, 수 연구 소개, 목 Q&A 답변, 금 랩미팅, 토 2분 발표, 일 없음.
```
